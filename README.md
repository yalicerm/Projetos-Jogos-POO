#Projetos-Jogos-POO

OBJETIVO:

Este repositório contém dois jogos desenvolvidos de forma colaborativa como parte da minha jornada no curso de Engenharia de Software e no aprendizado de desenvolvimento de aplicações. O objetivo principal do projeto foi aplicar na prática conceitos fundamentais de programação, estruturação de código e modelagem de sistemas em aplicações interativas.


DESCRIÇÃO DE CADA JOGO DESENVOLVIDO:

1. Space Wars
   O jogador controla um avião de caça com o objetivo de abater aeronaves inimigas que surgem no topo da tela. A movimentação é feita pelas setas direcionais horizontais, enquanto a barra de espaço dispara os tiros. Se um avião inimigo passar pela parte inferior da tela, o jogador perde uma de suas 3 vidas. Além disso, bombas irão surgir na tela, forçando o jogador a desviar. Caso o contrário irá perder uma vida.

2. Aprendi!
   Um quiz interativo de perguntas e respostas focado e conhecimentos sobre Programação Orientada a Objetos. Em cada partida, o jogador precisa responder a 10 questões sorteadas de um banco de 20 perguntas disponíveis. Há um cronômetro de 10 segundos para cada pergunta; se o tempo esgotar, o jogo revela a resposta correta e avança sem somar pontos. O jogador também conta com um recurso de "Pular" (Skip), que pode ser utilizado apenas uma vez por partida. Ao final, uma tela de encerramento exibe o desempenho total.


💻 Tecnologias e Conceitos Utilizados
* **Linguagem Principal: C#
* **Interface Gráfica:** Windows Forms e WPF
* **Plataforma de Desenvolvimento**: Visual Studio 
* **Programação Orientada a Objetos (POO):** Estruturação do código utilizando classes, herança, polimorfismo e associações para representar os elementos dos jogos.
* **Estruturas de Dados:** Uso de listas e coleções para gerenciar múltiplos objetos em tela (ex: inventário, inimigos, obstáculos).
* **Modelagem de Sistemas:** Diagramas UML Caso de Uso e Classe para modelação dos jogos.
